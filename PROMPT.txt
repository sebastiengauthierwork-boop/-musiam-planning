Amélioration du diagramme de Gantt du tableau de bord (PC et mobile).

OBJECTIF : permettre de naviguer jour par jour sur une fenêtre 
glissante de 7 jours, avec des flèches gauche/droite.

─────────────────────────────────────────
1. FENÊTRE GLISSANTE 7 JOURS
─────────────────────────────────────────
Actuellement le Gantt affiche une période fixe.
Passer à une fenêtre glissante de 7 jours :

- Par défaut : afficher les 7 jours à partir d'aujourd'hui
  (aujourd'hui = jour 1, puis J+1 ... J+6)
- Flèche gauche < : reculer d'1 jour (fenêtre glisse vers le passé)
- Flèche droite > : avancer d'1 jour (fenêtre glisse vers le futur)
- Le jour en cours (aujourd'hui) est toujours mis en évidence :
  colonne avec fond légèrement coloré (même couleur primaire 
  que le reste de l'interface, opacity réduite)

─────────────────────────────────────────
2. EN-TÊTE DES COLONNES JOURS
─────────────────────────────────────────
Pour chaque jour de la fenêtre, afficher sur 2 lignes :
  Lun        ← jour abrégé (3 lettres)
  02/06      ← date courte

- Aujourd'hui : texte en gras + indicateur visuel (point ou 
  soulignement de couleur)
- Jours passés : texte en gris (opacity réduite)
- Jours futurs : texte normal

─────────────────────────────────────────
3. CONTRÔLES DE NAVIGATION
─────────────────────────────────────────
Placer les flèches de part et d'autre du Gantt :

  [<]  Lun 02  Mar 03  Mer 04  Jeu 05  Ven 06  Sam 07  Dim 08  [>]

- Boutons < et > bien visibles, cliquables, avec hover effect
- Sur mobile : boutons suffisamment larges pour être tapables 
  (min 44×44px zone tactile)
- Ajouter aussi un bouton "Aujourd'hui" (ou "◎") entre les deux 
  flèches pour revenir immédiatement à la fenêtre par défaut 
  (J à J+6) en un clic

─────────────────────────────────────────
4. COMPORTEMENT DES DONNÉES
─────────────────────────────────────────
- Les codes horaires affichés dans le Gantt doivent se mettre 
  à jour en fonction de la fenêtre affichée
- Recharger les données depuis schedules pour la plage de dates 
  affichée (ne pas tout charger en mémoire)
- Afficher un loader léger pendant le chargement si la navigation 
  est rapide

─────────────────────────────────────────
5. RESPONSIVE MOBILE
─────────────────────────────────────────
Sur mobile, la fenêtre peut être réduite à 5 jours si 7 jours 
est trop serré (détecter la largeur disponible et adapter) :
- > 768px : 7 jours
- <= 768px : 5 jours
Les flèches et le bouton "Aujourd'hui" restent présents dans 
les deux cas.

Ne pas modifier le reste du tableau de bord.
Ne pas modifier budgetUtils.ts.
