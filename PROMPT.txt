Amélioration de la mise en forme du fichier Excel exporté depuis 
la page Calendrier des structures.

Le fichier est généré avec SheetJS (xlsx). Il faut passer à 
xlsx-style ou utiliser les options de style de SheetJS Pro —
vérifie quelle librairie est actuellement utilisée et adapte.

Si xlsx de base est utilisé (sans styles), remplacer par 
exceljs qui supporte nativement les styles :
  npm install exceljs

─────────────────────────────────────────
1. NOMBRES — RÉDUIRE LES DÉCIMALES
─────────────────────────────────────────
Les valeurs d'heures ont trop de décimales.
- Arrondir à 2 chiffres maximum après la virgule
- Format des cellules numériques : '0.00'
- Exemple : 58.5 s'affiche 58.50, pas 58.4999999...

─────────────────────────────────────────
2. LIGNE D'EN-TÊTE (ligne 1 : Jour, Janvier... Décembre, TOTAL)
─────────────────────────────────────────
- Fond : bleu foncé (#1E3A5F)
- Texte : blanc (#FFFFFF), gras
- Hauteur de ligne : 25px
- Texte centré horizontalement

─────────────────────────────────────────
3. COLONNE "Jour" (colonne A)
─────────────────────────────────────────
- Fond : gris clair (#F0F0F0)
- Texte : gris foncé (#333333), gras
- Centré horizontalement
- Largeur fixe : 8 caractères

─────────────────────────────────────────
4. CELLULES DE DONNÉES (jours × mois)
─────────────────────────────────────────
- Fond blanc par défaut
- Alterner une légère teinte sur les lignes paires :
  lignes paires → fond #F8F9FA (gris très très clair)
  lignes impaires → fond blanc #FFFFFF
- Texte centré
- Cellules vides (jour inexistant dans ce mois) : fond #EEEEEE

─────────────────────────────────────────
5. LIGNE "TOTAL" (dernière ligne)
─────────────────────────────────────────
- Fond : bleu foncé (#1E3A5F)
- Texte : blanc (#FFFFFF), gras
- Même style que la ligne d'en-tête
- Hauteur de ligne : 25px

─────────────────────────────────────────
6. COLONNE "TOTAL ANNUEL" (dernière colonne)
─────────────────────────────────────────
- Fond : bleu clair (#D6E4F0) sur toutes les cellules de données
- Texte : bleu foncé (#1E3A5F), gras
- La cellule intersection TOTAL × TOTAL ANNUEL :
  fond bleu foncé (#1E3A5F), texte blanc, gras

─────────────────────────────────────────
7. MISE EN PAGE GÉNÉRALE
─────────────────────────────────────────
- Largeur colonne A (Jour) : 8 caractères
- Largeur colonnes mois (B à M) : 12 caractères
- Largeur colonne TOTAL ANNUEL : 15 caractères
- Figer la première ligne (en-tête) et la première colonne (jours) :
  freeze pane sur B2 pour pouvoir scroller sans perdre les repères
- Bordures fines (#CCCCCC) sur toutes les cellules
